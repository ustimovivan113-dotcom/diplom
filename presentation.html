2 Проблема и решение

❌ Было

  • Сложные платформы с лишним функционалом
  • Нет контроля над контентом
  • Отсутствие ролей и модерации
  • Сложный деплой

✅ Стало

  • Чистый REST API
  • Полный контроль через админку
  • Роли user/admin + права доступа
  • Docker → деплой за 5 минут
Проблема: людям нужна простая площадка. Решение: API с авторизацией и фильтрацией.
